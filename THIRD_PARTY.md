# Third-party software

What this project uses and under which terms. `SDKS.lock` is the machine-readable list (exact version, source, licence and
whether it may be redistributed); `python3 tools/setup_sdks.py --check` compares a checkout with it. This is a summary for
contributors, not legal advice: read each licence before you redistribute anything.
